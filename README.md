# GURPS Action Chases

A shared chase tracker for GMs and players using **Foundry VTT 14** and **GURPS Game Aid 0.18.x**. Add characters, vehicles, drivers, and passengers with or without actors or tokens, then follow the tracker’s **Next action** prompts.

Version **0.2.5**. Use with **GURPS Action 2: Exploits**, pp. 31–35.

## Install or update

1. From Foundry's **Setup** screen, open **Add-on Modules**.
2. Paste `https://github.com/Farmeroz/gurps-action-chases/releases/latest/download/module.json` into **Manifest URL** and select **Install**.
3. Open your GURPS world, enable **GURPS Action Chases** in **Manage Modules**, and refresh connected browsers.

**Keep your existing `Chase · …` Journal entries.** They contain your saved chases. For a manual installation, download the versioned ZIP from [GitHub Releases](https://github.com/Farmeroz/gurps-action-chases/releases). No extra software or npm installation is needed.

## Start a chase

Press **Ctrl+Shift+C**, use the running-person button in the token toolbar, or choose **Action Chases** in the Combat sidebar. You can use the tracker without starting a combat encounter.

Try **Create example chase**, or create your own chase, add a participant to each side, assign player control, and choose **Show to players**. Players can open the tracker through the chat invitation.

## User guide

Open **Quick guide → Open full user guide (PDF)** in the tracker, or read [the included user guide](docs/User-Guide.pdf). It covers setup, player actions, combat, crew changes, saving, and recovery. The player reference and GM reference are easy to print.

The tracker saves accepted changes automatically. It does not move tokens or apply actor damage. Use GGA and the GM’s rulings for those steps. Consult the guide for the module’s interpretation options and automatic-result convention.
